# Data

This folder documents the dataset used for the Telecom Customer Churn Analytics project.

## Dataset Overview

The dataset contains telecom customer-level information used to analyze:

- Customer demographics
- Customer tenure
- Contract type
- Internet and service adoption
- Payment methods
- Monthly and total charges
- Customer churn status
- Churn categories and reasons
- Customer retention opportunities

## Data Preparation

The dataset was prepared and analyzed using Python and Pandas.

The data preparation process included:

- Data type validation
- Missing value analysis
- Duplicate checking
- Data cleaning
- Feature preparation
- Exploratory data analysis

## Privacy & Repository

The raw dataset is not included in this repository.

The analysis notebook contains the data preparation and analysis workflow used for the project.
